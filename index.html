Handleiding voor beheerders

Zo voeg je nieuwe activiteiten toe aan de agenda en zorg je dat ze zichtbaar worden op de website. Het wachtwoord voor beheerdersacties is TPZ2026.

1

Je krijgt het .js bestand

Je ontvangt het bijgewerkte bestand activiteiten.js, bijvoorbeeld van een collega die de nieuwe activiteit(en) via het webformulier heeft toegevoegd en gedownload, of je hebt dit zelf gedaan.

2

Open de GitHub-repository

Ga naar de repository TPZ-agenda op GitHub (via github.com, inloggen met je GitHub-account).

3

Voeg de nieuwe activiteit(en) toe aan activiteiten.js

Let op: vervang niet de hele inhoud van het bestand — het gedownloade bestand bevat alleen de nieuw toegevoegde activiteit(en), niet de bestaande. Als je alles overschrijft, verdwijnen de activiteiten die al in de agenda stonden.

Ga zo te werk:

  1. Open het gedownloade bestand en kopieer daaruit alle nieuwe activiteit-blokjes in één keer: begin bij de eerste { en eindig bij de laatste } (met alles ertussen). Staat er maar één nieuwe activiteit in, dan is dat vanzelf gewoon dat ene blokje van { tot }.
  2. Open op GitHub het bestand activiteiten.js → klik op het potloodicoon (Edit this file, rechtsboven).
  3. Zoek helemaal bovenaan de regel const ACTIVITEITEN_DATA = [. Zet je cursor direct ná het blokhaakje [ aan het einde van die regel en druk op Enter om een nieuwe regel te maken.
  4. Plak op die nieuwe regel het gekopieerde stuk (van de eerste { tot en met de laatste }).
  5. Zet direct achter de laatste } die je zojuist geplakt hebt een komma , — dit moet vóór de eerstvolgende { staan (die van de eerste bestaande activiteit).
  6. Klik "Commit changes" → klik nogmaals "Commit changes" in het pop-upvenster.
4

GitHub Pages publiceert automatisch

Na het committen publiceert GitHub Pages de website automatisch. Binnen ±1 minuut zijn de nieuwe activiteiten zichtbaar op de website. Je hoeft niets extra's te doen.

Activiteiten bewerken of verwijderen: Klik op een activiteit in de agenda → kies "Bewerken" of "Verwijderen" (wachtwoord vereist) → download het bijgewerkte activiteiten.js bestand → upload naar GitHub zoals beschreven in stap 2–4 hierboven.

Vragen of problemen? Neem contact op met de beheerder van de repository.
